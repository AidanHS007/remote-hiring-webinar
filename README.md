# Remote hiring webinar concept

Standalone static site based on Aidan Herold J's Figma webinar landing-page concept. Open `index.html` in a browser or host this directory with GitHub Pages. No build step, cookies, analytics, external dependencies or form backend. The form validates locally and does not send or store inputs. The original May 24, 2026 event date has passed; this is a portfolio/demo concept and is not affiliated with Instahyre.
